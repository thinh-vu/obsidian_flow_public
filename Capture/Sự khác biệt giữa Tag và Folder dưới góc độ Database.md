## Cơ chế
- **Folder:** Là cấu trúc phân cấp vật lý (Physical Storage). Một file chỉ có thể nằm trong một folder.
- **Tag:** Là metadata phi tập trung. Một file có thể có hàng chục tags.

## Bài học
Sử dụng Tag để phân loại tính chất và Folder để phân loại trạng thái (như FLOW). Đừng lạm dụng folder để phân loại chủ đề vì nó sẽ tạo ra sự cứng nhắc.

## Mối liên hệ
Quy tắc folder trong hệ thống FLOW: Capture, Track, Forge, Exhibit.
